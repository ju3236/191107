# 잿빛 등대 — 명일방주 자캐 AU 타워디펜스

로도스 아일랜드 행동대 「등대」를 지휘하는 명일방주 자캐 AU 웹게임입니다. 적 이름·스탯·능력은 원작 적 도감(Aceship AN-EN-Tags 데이터)을 참고했습니다. 라이브러리나 빌드 없이 브라우저에서 바로 돌아갑니다.

## 실행

`index.html`을 브라우저로 열면 됩니다.
(이미지를 쓰려면 로컬 서버가 편합니다: `npx serve .` 또는 `python3 -m http.server`)

## 화면 구성 (원작 인터페이스 참고)

| 화면 | 들어가는 법 | 하는 일 |
|---|---|---|
| 메인 | 처음 화면 | 비서 오퍼레이터와 대사, 지휘관 레벨, 진행도, 메뉴 타일. 비서를 누르면 대사가 바뀝니다 |
| 전투 | 작전 개시 | 기울어진 3D풍 맵 위에 캐릭터 그림이 서서 싸웁니다 |
| 오퍼레이터 목록 | 메인 → OPERATOR | 카드 목록, 오른쪽 직군 필터, 위쪽 정렬(직군/레어도/코스트) |
| 오퍼레이터 상세 | 목록에서 카드 누르기 | 스탯, 공격 범위, 세부 직군 특성, 재능, **스킬 3개 중 선택**, 프로필, 비서 지정 |
| 편성 | 메인 → SQUADS, 또는 작전 선택 후 | 12칸 슬롯, 빠른 편성, 비우기, 작전 개시 |
| 작전 목록 | 메인 → TERMINAL | 에피소드 탭(EP 01 · EP 02), 스테이지 16개(1-1 ~ 2-8), 스토리 다시 보기, 적 정보(능력 포함), 맵 미리보기 |

효과음은 `sfx.js`에서 파일 없이 직접 만들어 냅니다. 설정(메인 화면 톱니바퀴)이나 전투 중 일시정지 메뉴에서 끌 수 있습니다.

메인 화면 왼쪽 위 아이콘: 설정(효과음 켜기/끄기, 데이터 초기화) · 세계관 소개 · 기록(지나간 스토리 다시 보기)

## 통합전략 — 「가라앉은 등대」 (바다 테마)

메인 화면 → **INTEGRATED STRATEGIES**. 원작의 통합전략처럼 한 판씩 탐색하는 로그라이크 모드입니다. 이성은 쓰지 않습니다.

- **분대**를 고르고 **모집권**으로 보유한 오퍼레이터를 모집합니다. 모집과 랭크 상승에는 **희망**이 듭니다 (6성 3, 5성 2, 4성 1).
- 모집한 오퍼레이터는 **랭크 상승 전**(능력치 80%, 1스킬과 1재능만)으로 합류하고, 분대 화면에서 랭크 상승하면 모든 능력치·재능과 원하는 스킬을 씁니다.
- 작전에 데려갈 수 있는 인원은 **편성 가능 인원수**(기본 8명, 최대 13명)까지이며, 분대가 더 많으면 작전 전에 고릅니다.
- 층 지도에서 길을 골라 진행합니다: 작전 · 긴급 작전 · 불온한 조우 · 교역소 · 안식처, 층 끝에는 관문 작전이나 보스. 4층(얕은 여울 → 잠긴 교회 → 침몰선의 무덤 → 빛 없는 심해) 끝의 「이샤믈라, 부식의 마음」을 쓰러뜨리면 완주입니다.
- 작전 중 적이 돌파하면 탐색 전체의 **목표 HP**가 줄고(**실드**가 있으면 실드부터), 0이 되면 탐색이 끝납니다. **오리지늄각뿔**은 교역소 화폐, **지휘 경험치**가 쌓이면 레벨이 올라 희망을 얻습니다.
- **소장품**: 원작 「쉐이의 기이한 계원」 소장품 294종(이름·효과·설명·아이콘은 원작 그대로, © Hypergryph / Yostar, 비상업 팬 게임 용도). 이 가운데 227종이 등장하고, 주화·화경지·쉐이의 잔식·소환물·탄약·전술 도구·전용 루트처럼 이 AU에 없는 시스템과 관련된 67종은 도감에만 「등장하지 않음」으로 표시됩니다. 사촉인은 랭크 상승한 오퍼레이터, 요괴는 시본으로 바꿔 적용하고, 원작과 다르게 적용되는 점은 소장품마다 「이 게임에서는」으로 적혀 있습니다. 희귀도(평범·진귀·매우 진귀)는 원본 자료에 없어 효과 크기에 맞춰 정했습니다.
- 바다 전용 요소: 시본 적(원작 적 도감 참고), **명흔**(맵 기호 `~`: 위의 오퍼레이터는 방어력 -30%·HP 감소, 시본은 HP 회복), **신경 손상**(1000까지 쌓이면 800 피해 + 6초 기절).
- 탐색이 끝나면 점수에 따라 용문폐를 받고, 참가한 오퍼레이터의 신뢰도가 오릅니다. 진행 중인 탐색은 저장되므로 나갔다가 이어서 할 수 있습니다.
- 분대·모집권·층·작전 맵·불온한 조우는 `is-data.js`, 소장품은 `is-relics.js`(그림은 `img/relic/`)에서 고칩니다. 효과 키는 각 파일 주석에 정리되어 있습니다.

## 계정 · 헤드헌팅 · 구매센터 · 관리자

원작과 같은 이름의 재화와 시스템을 씁니다: 이성(6분에 1 회복, 작전마다 소모), 용문폐, 합성옥, 오리지늄, 헤드헌팅 허가증, 10회 헤드헌팅 허가증, 잠재력, 고급·초급 자격증.

- **헤드헌팅**: 합성옥 600 또는 허가증 1장으로 1회. 확률은 원작과 같고(6성 2%, 5성 8%, 4성 50%, 3성 40%), 50회 연속 6성이 없으면 이후 1회마다 6성 확률 +2%. 중복이면 잠재력이 오릅니다. 처음에는 지원 오퍼레이터만 보유하고, 나머지는 헤드헌팅으로 얻습니다.
- **구매센터**: 실제 결제는 없습니다. 「결제 요청」을 보내면 관리자가 승인했을 때 재화가 들어옵니다. 오리지늄 → 합성옥 교환(1:180)은 바로 됩니다.
- **관리자**: 결제 요청 승인/거절, 플레이어에게 재화·오퍼레이터 직접 지급, **오퍼레이터 실장**(이름·직군·스탯·재능·스킬·그림을 게임 안에서 입력), **헤드헌팅 배너 여러 개**(최대 12개: 배너 이름·작은 설명·종료일·확률 UP 오퍼레이터, 순서 바꾸기·삭제). 종료일이 지난 배너는 플레이어에게 보이지 않습니다. 6성 천장 카운트는 모든 배너가 함께 씁니다.

### 두 사람이 각자 계정으로 하려면 (claude.ai 링크에서만)

계정·결제 요청·관리자 기능은 claude.ai 아티팩트의 공용 데이터 기능을 씁니다. 그 밖의 곳(파일로 열기, GitHub Pages)에서는 이 브라우저에만 저장되고 결제 요청·관리자 기능은 꺼집니다.

1. 게임 페이지의 **공유(Share)** 메뉴에서 **링크 공개(Anyone with the link)를 끄고**, 지인을 **이메일로 초대해 편집자(Editor) 권한**을 줍니다.
2. 두 사람 모두 claude.ai에 로그인한 채로 링크를 엽니다. 각자 계정에 따로 저장됩니다.
3. 편집 권한이 있는 사람 = 관리자입니다. 메인 화면에 「ADMIN」 타일이 생깁니다.

개인 계정에서는 소유자와 이메일로 초대한 편집자만 데이터를 저장할 수 있고, 링크 공개가 켜져 있으면 편집자도 저장할 수 없습니다.

## 조작

| 동작 | 방법 |
|---|---|
| 배치 | 아래 카드 선택 → 칸 선택 → 드래그하거나 화살표를 눌러 방향 결정 (가운데 누르면 취소) |
| 스킬 / 철수 | 배치된 오퍼레이터 누르기 → 정보창의 버튼 |
| 배속 / 일시정지 | 오른쪽 위 버튼 |
| PC 단축키 | `Q` 철수 · `E` 스킬 발동 · `F` 1배속/2배속 · `Space` 일시정지 · `Esc` 취소. Q·E는 정보창이 열린 오퍼레이터, 없으면 마우스를 올린 오퍼레이터에 적용 |

- 근접 직군(뱅가드·가드·디펜더·스페셜리스트)은 **지면(어두운 칸)**, 원거리 직군(스나이퍼·캐스터·메딕)은 **고지대(밝은 칸)**에 배치합니다.
- 코스트는 1초에 1씩 찹니다. 철수하면 코스트를 절반 돌려받고, 재배치 대기 시간이 생깁니다.
- 노란 `!` 표시가 뜨면 수동 스킬을 쓸 수 있습니다. 자동 스킬은 SP가 차면 저절로 발동됩니다.
- 비행 적(◇ 모양)은 저지되지 않고, 근접 오퍼레이터는 공격할 수 없습니다.
- 물리 피해 = 공격력 − 방어력, 마법 피해 = 공격력 × (1 − 마법 저항%), 최소 피해는 공격력의 5%입니다.

## 자캐로 바꾸기 — `data.js`만 수정

| 항목 | 위치 |
|---|---|
| 게임 제목, 세계관 소개, 지휘관 호칭, 챕터 이름 | `GAME_INFO` |
| 오퍼레이터(자캐) 이름·영문 이름·레어도·태그·종족·직군·프로필·비서 대사·스탯·스킬·공격 범위 | `OPERATORS` |
| 적 | `ENEMIES` |
| 에피소드(작전 목록 탭) | `CHAPTERS` |
| 맵·웨이브·스테이지 전후 스토리 (스테이지마다 `chapter`로 에피소드 지정) | `STAGES` |

- 캐릭터 그림: `img/` 폴더에 그림을 넣고 오퍼레이터에 `image: 'img/rea.png'`를 추가하면 임시 일러스트 대신 그림이 나옵니다. 메인 화면·카드·상세 화면에 쓰이니 **세로로 긴 전신/반신 그림**을 추천합니다. (위쪽 기준으로 잘립니다)
- 적 그림: `img/enemy/<적 id>.png`에 원작 적 도감 아이콘이 들어 있습니다(© Hypergryph / Yostar, Aceship Arknight-Images). 비상업 팬 게임 용도로만 써 주세요. 다른 그림을 쓰려면 적 데이터에 `image: '경로'`를 넣으면 됩니다.
- 맵 기호: `#` 벽, `.` 지면(배치 가능), `-` 통로(배치 불가), `^` 고지대, `R` 적 침입 지점, `B` 방어 지점. 적은 R에서 B까지 가장 짧은 지면 경로로 걸어옵니다.
- 스토리 대사: `{ who: '오퍼레이터id', text }`, `{ name: '아무 이름', text }`, `{ text }`(나레이션)
- 스테이지에 `pos: 40`처럼 넣으면 작전 목록 화면에서 그 노드의 세로 위치(%)를 정할 수 있습니다.

- 스킬·재능·적 능력에 쓸 수 있는 효과 목록은 `data.js` 각 구역 맨 위 주석에 정리되어 있습니다.
- 서포터 직군(고지대, 마법 대미지)과 세부 직군 투사·약화자가 있습니다. 재능 효과 `analyze`(분석 누적: 방어력·마법 저항 감소), `deduce`(분석 완료 적 피해 증가, 파트너 추가 보너스), `focus`(같은 적 연속 공격 시 방어력 무시), `partnerSpeed`(약화된 적 공격 시 공격 속도, 파트너 편성 시 강화), 스킬 효과 `analyzeRate`, `slowAnalyzed`, `priority: 'lowDef'`(방어력 낮은 적 우선)를 쓸 수 있습니다.
- 세부 직군 치료사(메딕)·중추술사(캐스터). 재능 `listen`(같은 아군 연속 치료 시 치료량 증가), `protect`(범위 안 아군 상태 이상 단축), `proof`(같은 적 N회 공격 시 「입증」: 마법 저항 감소), `argue`(입증된 적 추가 마법 피해), 스킬 `resBuff`, `hot`, `burstHeal`, `allyGuard`, `extraHit`, `proofRate`, `priority: 'proof'`, `proofRes`, `proofBlast`.
- 소환물: 오퍼레이터에 `summon: { … }`(소환물 스탯)을 넣으면, 그 오퍼레이터를 배치했을 때 소환물 카드가 생깁니다. 소환물은 배치 인원을 차지하지 않고, 주인이 퇴각하면 함께 퇴각합니다 (예: 키스 엔라이튼의 하우스 가드).
- 장치: `summons: [ … ]`처럼 여러 개를 넣을 수 있고, `charges`(배치 가능 횟수)를 주면 그 횟수만큼 여러 개를 설치할 수 있습니다. 0이면 스킬로 얻기 전까지 카드가 숨겨집니다. `noDir: true`면 방향을 고르지 않고 바로 설치됩니다 (예: 클라운피쉬의 해류 부표).
- 훈련장: 작전 목록 하단 탭의 「훈련장」. 지금 편성으로 들어가며, 적이 돌파해도 목숨이 줄지 않고, 배치 코스트가 무한이고, 재배치 2초·SP 회복 3배입니다. 적(공격하지 않는 표적 포함)은 끝없이 반복해서 나옵니다. 맵과 적은 data.js의 `PRACTICE_STAGE`에서 바꿉니다.
- 3장 「철의 문」(아이언 게이트 사건)과 4장 「오늘의 변수」(기업의 남은 연구소)에서 펠릭스·아이언클래드·터너·클라운피쉬·주영하·던베인을 비롯한 모든 오퍼레이터가 이야기에 나옵니다.
- 작전 목록 하단 탭: 메인 스토리 · 물자 비축 · 칩 탐색 · 훈련장 · 통합전략(메인 화면에서는 빠지고 여기로 옮김). 물자 비축(전술 연습=작전기록 · 화물 운송=용문폐 · 공중 위협=스킬개론)과 칩 탐색(난공불락=디펜더·메딕 · 추풍낙엽=스나이퍼·캐스터 · 솔선수범=뱅가드·서포터 · 질풍노도=가드·스페셜리스트)은 원작처럼 요일별로 열리며(오전 4시 기준, 닫힌 날은 「진입 불가」), 1-4 클리어 후 개방됩니다. 같은 시리즈의 이전 단계를 깨면 다음 단계가 열립니다. 시리즈·개방 요일은 data.js의 `SUPPLY_SERIES`에서 바꿉니다.
- 드롭 테이블(`TRAIN.dropTable`): 메인 스토리 작전은 용문폐(이성 × 12)와 작전마다 정해진 주요 재료(별 3개면 확정 · 추가 1개 50%)와 부가 재료(25%)만 나옵니다. 1~2장은 중급 재료, 3~4장은 고급 재료이고, 스테이지에 `mainDrop` / `subDrop`을 넣으면 직접 지정합니다. 작전기록·용문폐 대량·스킬개론·직군 칩은 물자 비축과 칩 탐색에서만 나옵니다. 작전 패널에 드롭이 표시됩니다.
- 획득처: 정예화 · 스킬 육성 · 가공소 화면의 재료나 창고의 아이템을 누르면 그 재료가 나오는 작전(주요 드롭 → 물자 비축 고정 → 일반 → 확률 순)과 가공소 레시피가 나오고, 「이동」으로 그 작전(메인 스토리 장 · 시리즈 자동 선택)으로 바로 갑니다. 미해금 · 오늘 미개방이면 표시만 합니다.
- 가공소: 창고 오른쪽 위 「가공소」. 고급 재료(같은 계열 중급 재료 4 + 용문폐 300) · 듀얼칩(같은 직군 칩 3 + 용문폐 2000) · 스킬개론(아래 권 3). 레시피는 data.js의 `WORKSHOP`.
- 임무: 메인 화면 「MISSION」. 일일(오전 4시) · 주간(월요일 오전 4시) 임무와 모두 완료 보상, 「모두 수령」. 작전 완료(대리 작전 포함) · 이성 소모 · 물자 비축/칩 탐색 · 육성 · 정예화 · 가공 · 헤드헌팅 횟수를 셉니다. 내용과 보상은 data.js의 `MISSIONS`. 기록 화면은 왼쪽 위 책 아이콘으로 엽니다.
- 아이템 아이콘: `img/item/<아이템 id>.png` (원작 이미지, © Hypergryph/Yostar). 파일이 없는 아이템은 style.css의 도형 아이콘으로 표시됩니다.
- 잠재: 헤드헌팅 중복으로 오르는 잠재 2~6에서 배치 코스트 -1 · 재배치 -4초 · 공격력 +4% · 코스트 -1 · 공격력 +3%·HP +5%를 차례로 얻습니다(`TRAIN_RULE.potential`, 오퍼레이터별 `potentials`로 덮어쓰기).
- 신뢰도: 0~100%에 비례해 직군별 능력치 보너스(`TRAIN_RULE.trustBonus`, 오퍼레이터별 `trustBonus`). 프로필의 첫 문단은 「기본 정보」, 나머지 문단은 「기록 N」으로 신뢰도 25~100%에 따라 열립니다. 상세 화면의 「잠재 · 신뢰도」 표시를 누르면 효과를 볼 수 있습니다.
- 기반시설: 메인 화면 「BASE」. 무역소(용문폐) · 제조소(경험치 → 작전기록) · 응접실(배치한 오퍼레이터 신뢰도 상승). 오퍼레이터를 배치해야 가동하고, 오퍼레이터마다 효율 +35%(맞는 직군 +20%, 정예화 단계마다 +5%). 생산물은 보관 한도(레벨별 시간)까지 쌓이고, 용문폐와 중급/고급 재료로 Lv.3까지 확장합니다. 수치는 data.js의 `BASE`.
- 오퍼레이터 파일: 상세 화면 「파일」. 기본 정보(코드네임 · 본명 · 종족 · 소속 · 직군 · 합류일), 체검 보고서(오퍼레이터에 `medical: '…'`을 넣으면 신뢰도 10%에 열림), 기록 1~N(프로필 문단, 신뢰도), 승진 기록(`promoRecord` 또는 승진 후 대화, 2차 정예화).
- 대리 작전: 별 3개로 깬 작전은 「대리 지휘」를 켜고 ×1~×6을 골라 이성만 쓰고 바로 보상을 받을 수 있습니다.
- 스킬 레벨(1~7, 모든 스킬 공통, 0정은 4까지)과 특화(스킬마다 1~3, 2정 + 레벨 7): 상세 화면의 「스킬 육성」. 데이터의 스킬 수치는 특화 3 기준이고, 낮으면 `TRAIN_RULE.skillPower` 비율로 약해집니다.
- 육성: 오퍼레이터마다 레벨과 정예화 단계가 있습니다(0정 70 / 1정 80 / 2정 90 만렙). 1정에서 2스킬·1재능, 2정에서 3스킬·2재능이 열립니다. 작전기록·용문폐로 레벨업하고, 칩·재료·용문폐로 정예화합니다. 재료는 작전 클리어 보상으로 얻습니다. 규칙과 재료는 data.js의 `TRAIN_RULE`, 계산은 train.js에 있습니다. 통합전략은 육성과 관계없이 자체 규칙(랭크 상승)을 씁니다.
- 의상(스킨): data.js의 `SKINS`에 `{ id, op, name, brand, image, price, desc }`를 넣으면 구매센터 「의상」 탭과 오퍼레이터 상세 화면의 「의상」 버튼에 나옵니다. 오리지늄으로 사고, 갈아입으면 전투·카드·대화 모두 그 그림으로 바뀝니다.
- 던베인(여명)의 「오늘의 변수」는 배치할 때와 2·3스킬을 발동할 때 순풍·햇빛·중력 중 하나를 무작위로 뽑습니다(`DAILY_ARTS` in data.js). 3스킬은 지속 시간이 무한이고 직접 끌 수 있어, 끄고 다시 발동하면 다시 뽑을 수 있습니다.
- 오퍼레이터 고유 이펙트는 data.js의 `OP_VFX`에서 정합니다(투사체·근접 타격 모양, 색, 스킬 발동 파티클).
- 대사(`voice`) 키: 획득 `obtain` · 비서 `assistant` · 대화 `talk` · 승진 후 대화 `promo`(신뢰도 120%에서 해금) · 신뢰도 `trust40`/`trust100`/`trust150`/`trust200` · 편성 `squad` · 대장 `leader` · 출발 `depart` · 개시 `start` · 선택 `select` · 배치 `deploy` · 전투 `combat` · 별 3개 완료 `clear` · 별 3개 미만 완료 `clear2` · 실패 `fail` · 시설 배치 `base`(음성 기록에만 표시) · 터치 `touch` · 신뢰 터치 `trustTouch`(신뢰도 100%부터) · 방치 `idle`(메인 화면에서 1분 동안 입력이 없을 때) · 인사 `greet`(게임을 켜고 처음 메인 화면에 왔을 때). 터치 대사는 메인 화면 비서 그림을 누르면 나옵니다.

진행 상황·편성·비서·스킬·재화는 claude.ai에서는 계정(공용 데이터의 `players/<id>`)에, 그 밖에서는 브라우저 localStorage에 저장됩니다.
구매센터 상품·아이템·헤드헌팅 확률은 `data.js` 맨 아래 `ITEMS`, `SHOP`, `GACHA`에서 바꿀 수 있습니다. 기본 이벤트 배너는 `GACHA.banners`에 있고, 관리자가 게임 안에서 배너를 한 번 저장하면 그 목록으로 바뀝니다.
