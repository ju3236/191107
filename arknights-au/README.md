# 잿빛 등대 — 명일방주 자캐 AU 타워디펜스

로도스 아일랜드 행동대 「등대」를 지휘하는 명일방주 자캐 AU 웹게임입니다. 적 이름·스탯·능력은 원작 적 도감(Aceship AN-EN-Tags 데이터)을 참고했습니다. 라이브러리나 빌드 없이 브라우저에서 바로 돌아갑니다.

## 실행

`index.html`을 브라우저로 열면 됩니다.
(이미지를 쓰려면 로컬 서버가 편합니다: `npx serve .` 또는 `python3 -m http.server`)

## 화면 구성 (원작 인터페이스 참고)

| 화면 | 들어가는 법 | 하는 일 |
|---|---|---|
| 메인 | 처음 화면 | 비서 오퍼레이터와 대사, 지휘관 레벨, 진행도, 메뉴 타일. 비서를 누르면 대사가 바뀝니다 |
| 전투 | 작전 개시 | 기울어진 3D풍 맵 위에 캐릭터 그림이 서서 싸웁니다 |
| 오퍼레이터 목록 | 메인 → OPERATOR | 카드 목록, 오른쪽 직군 필터, 위쪽 정렬(직군/레어도/코스트) |
| 오퍼레이터 상세 | 목록에서 카드 누르기 | 스탯, 공격 범위, 세부 직군 특성, 재능, **스킬 3개 중 선택**, 프로필, 비서 지정 |
| 편성 | 메인 → SQUADS, 또는 작전 선택 후 | 12칸 슬롯, 빠른 편성, 비우기, 작전 개시 |
| 작전 목록 | 메인 → TERMINAL | 에피소드 탭(EP 01 · EP 02), 스테이지 16개(1-1 ~ 2-8), 스토리 다시 보기, 적 정보(능력 포함), 맵 미리보기 |

효과음은 `sfx.js`에서 파일 없이 직접 만들어 냅니다. 설정(메인 화면 톱니바퀴)이나 전투 중 일시정지 메뉴에서 끌 수 있습니다.

메인 화면 왼쪽 위 아이콘: 설정(효과음 켜기/끄기, 데이터 초기화) · 세계관 소개 · 기록(지나간 스토리 다시 보기)

## 계정 · 헤드헌팅 · 구매센터 · 관리자

원작과 같은 이름의 재화와 시스템을 씁니다: 이성(6분에 1 회복, 작전마다 소모), 용문폐, 합성옥, 오리지늄, 헤드헌팅 허가증, 10회 헤드헌팅 허가증, 잠재력, 고급·초급 자격증.

- **헤드헌팅**: 합성옥 600 또는 허가증 1장으로 1회. 확률은 원작과 같고(6성 2%, 5성 8%, 4성 50%, 3성 40%), 50회 연속 6성이 없으면 이후 1회마다 6성 확률 +2%. 중복이면 잠재력이 오릅니다. 처음에는 지원 오퍼레이터만 보유하고, 나머지는 헤드헌팅으로 얻습니다.
- **구매센터**: 실제 결제는 없습니다. 「결제 요청」을 보내면 관리자가 승인했을 때 재화가 들어옵니다. 오리지늄 → 합성옥 교환(1:180)은 바로 됩니다.
- **관리자**: 결제 요청 승인/거절, 플레이어에게 재화·오퍼레이터 직접 지급, **오퍼레이터 실장**(이름·직군·스탯·재능·스킬·그림을 게임 안에서 입력), **헤드헌팅 배너 여러 개**(최대 12개: 배너 이름·작은 설명·종료일·확률 UP 오퍼레이터, 순서 바꾸기·삭제). 종료일이 지난 배너는 플레이어에게 보이지 않습니다. 6성 천장 카운트는 모든 배너가 함께 씁니다.

### 두 사람이 각자 계정으로 하려면 (claude.ai 링크에서만)

계정·결제 요청·관리자 기능은 claude.ai 아티팩트의 공용 데이터 기능을 씁니다. 그 밖의 곳(파일로 열기, GitHub Pages)에서는 이 브라우저에만 저장되고 결제 요청·관리자 기능은 꺼집니다.

1. 게임 페이지의 **공유(Share)** 메뉴에서 **링크 공개(Anyone with the link)를 끄고**, 지인을 **이메일로 초대해 편집자(Editor) 권한**을 줍니다.
2. 두 사람 모두 claude.ai에 로그인한 채로 링크를 엽니다. 각자 계정에 따로 저장됩니다.
3. 편집 권한이 있는 사람 = 관리자입니다. 메인 화면에 「ADMIN」 타일이 생깁니다.

개인 계정에서는 소유자와 이메일로 초대한 편집자만 데이터를 저장할 수 있고, 링크 공개가 켜져 있으면 편집자도 저장할 수 없습니다.

## 조작

| 동작 | 방법 |
|---|---|
| 배치 | 아래 카드 선택 → 칸 선택 → 드래그하거나 화살표를 눌러 방향 결정 (가운데 누르면 취소) |
| 스킬 / 철수 | 배치된 오퍼레이터 누르기 → 정보창의 버튼 |
| 배속 / 일시정지 | 오른쪽 위 버튼 |
| PC 단축키 | `Q` 철수 · `E` 스킬 발동 · `F` 1배속/2배속 · `Space` 일시정지 · `Esc` 취소. Q·E는 정보창이 열린 오퍼레이터, 없으면 마우스를 올린 오퍼레이터에 적용 |

- 근접 직군(뱅가드·가드·디펜더·스페셜리스트)은 **지면(어두운 칸)**, 원거리 직군(스나이퍼·캐스터·메딕)은 **고지대(밝은 칸)**에 배치합니다.
- 코스트는 1초에 1씩 찹니다. 철수하면 코스트를 절반 돌려받고, 재배치 대기 시간이 생깁니다.
- 노란 `!` 표시가 뜨면 수동 스킬을 쓸 수 있습니다. 자동 스킬은 SP가 차면 저절로 발동됩니다.
- 비행 적(◇ 모양)은 저지되지 않고, 근접 오퍼레이터는 공격할 수 없습니다.
- 물리 피해 = 공격력 − 방어력, 마법 피해 = 공격력 × (1 − 마법 저항%), 최소 피해는 공격력의 5%입니다.

## 자캐로 바꾸기 — `data.js`만 수정

| 항목 | 위치 |
|---|---|
| 게임 제목, 세계관 소개, 지휘관 호칭, 챕터 이름 | `GAME_INFO` |
| 오퍼레이터(자캐) 이름·영문 이름·레어도·태그·종족·직군·프로필·비서 대사·스탯·스킬·공격 범위 | `OPERATORS` |
| 적 | `ENEMIES` |
| 에피소드(작전 목록 탭) | `CHAPTERS` |
| 맵·웨이브·스테이지 전후 스토리 (스테이지마다 `chapter`로 에피소드 지정) | `STAGES` |

- 캐릭터 그림: `img/` 폴더에 그림을 넣고 오퍼레이터에 `image: 'img/rea.png'`를 추가하면 임시 일러스트 대신 그림이 나옵니다. 메인 화면·카드·상세 화면에 쓰이니 **세로로 긴 전신/반신 그림**을 추천합니다. (위쪽 기준으로 잘립니다)
- 적 그림: `img/enemy/<적 id>.png`에 원작 적 도감 아이콘이 들어 있습니다(© Hypergryph / Yostar, Aceship Arknight-Images). 비상업 팬 게임 용도로만 써 주세요. 다른 그림을 쓰려면 적 데이터에 `image: '경로'`를 넣으면 됩니다.
- 맵 기호: `#` 벽, `.` 지면(배치 가능), `-` 통로(배치 불가), `^` 고지대, `R` 적 침입 지점, `B` 방어 지점. 적은 R에서 B까지 가장 짧은 지면 경로로 걸어옵니다.
- 스토리 대사: `{ who: '오퍼레이터id', text }`, `{ name: '아무 이름', text }`, `{ text }`(나레이션)
- 스테이지에 `pos: 40`처럼 넣으면 작전 목록 화면에서 그 노드의 세로 위치(%)를 정할 수 있습니다.

- 스킬·재능·적 능력에 쓸 수 있는 효과 목록은 `data.js` 각 구역 맨 위 주석에 정리되어 있습니다.
- 서포터 직군(고지대, 마법 대미지)과 세부 직군 투사·약화자가 있습니다. 재능 효과 `analyze`(분석 누적: 방어력·마법 저항 감소), `deduce`(분석 완료 적 피해 증가, 파트너 추가 보너스), `focus`(같은 적 연속 공격 시 방어력 무시), `partnerSpeed`(약화된 적 공격 시 공격 속도, 파트너 편성 시 강화), 스킬 효과 `analyzeRate`, `slowAnalyzed`, `priority: 'lowDef'`(방어력 낮은 적 우선)를 쓸 수 있습니다.
- 세부 직군 치료사(메딕)·중추술사(캐스터). 재능 `listen`(같은 아군 연속 치료 시 치료량 증가), `protect`(범위 안 아군 상태 이상 단축), `proof`(같은 적 N회 공격 시 「입증」: 마법 저항 감소), `argue`(입증된 적 추가 마법 피해), 스킬 `resBuff`, `hot`, `burstHeal`, `allyGuard`, `extraHit`, `proofRate`, `priority: 'proof'`, `proofRes`, `proofBlast`.
- 대사(`voice`) 키: 획득 `obtain` · 비서 `assistant` · 대화 `talk` · 승진 후 대화 `promo`(신뢰도 120%에서 해금) · 신뢰도 `trust40`/`trust100`/`trust150`/`trust200` · 편성 `squad` · 대장 `leader` · 출발 `depart` · 개시 `start` · 선택 `select` · 배치 `deploy` · 전투 `combat` · 별 3개 완료 `clear` · 별 3개 미만 완료 `clear2` · 실패 `fail` · 시설 배치 `base`(음성 기록에만 표시) · 터치 `touch` · 신뢰 터치 `trustTouch`(신뢰도 100%부터) · 방치 `idle`(메인 화면에서 1분 동안 입력이 없을 때) · 인사 `greet`(게임을 켜고 처음 메인 화면에 왔을 때). 터치 대사는 메인 화면 비서 그림을 누르면 나옵니다.

진행 상황·편성·비서·스킬·재화는 claude.ai에서는 계정(공용 데이터의 `players/<id>`)에, 그 밖에서는 브라우저 localStorage에 저장됩니다.
구매센터 상품·아이템·헤드헌팅 확률은 `data.js` 맨 아래 `ITEMS`, `SHOP`, `GACHA`에서 바꿀 수 있습니다. 기본 이벤트 배너는 `GACHA.banners`에 있고, 관리자가 게임 안에서 배너를 한 번 저장하면 그 목록으로 바뀝니다.
